# party-inventory-agent

This project implements a multi-agent LLM pipeline for retail inventory management. It demonstrates advanced agentic patterns including Planner-Executor orchestration, deterministic guardrails, Human-in-the-Loop (HITL) enforcement, and LLM-as-Judge evaluation, applied to a party supply store context.


🌟 Core Features

Multi-Agent Architecture


Planner (claude-sonnet-4-6): The reasoning brain that formulates plans, interprets unstructured signals (events/promotions), and decides which tools to call.
Executor (claude-haiku-4-5): A lightweight worker that efficiently summarizes raw tool data, saving tokens and latency.
Judge (claude-haiku-4-5): An automated evaluator that scores the Planner's final output across 7 dimensions (e.g., hallucination avoidance, reasoning transparency, rule compliance) before delivery.


Deterministic Safety Guardrails (HITL)
A Python-based state-machine layer that guarantees process compliance. It strictly enforces ABC inventory rules, ensuring that high-value (A-class) restocking decisions always require human approval, injecting safety calls if the Planner skips them.

Event-Aware Demand Planning
Interprets unstructured text (e.g., "graduation weekend for 450 students", supplier delay notices) and translates them into structured demand spikes and supply risk variables.

Robust FinOps & Telemetry
Built-in tracking of token usage, latency (planner vs. tool vs. judge), and dollar costs per pipeline run.


🛠️ Tool Arsenal


interpret_unstructured_signals — Translates raw event briefs and supplier notices into structured demand/supply signals.
check_inventory — Looks up real-time stock levels and reorder thresholds.
get_sales_forecast — Calculates future demand with optional peak-event multipliers.
calculate_reorder — Identifies shortfalls and estimates restocking costs.
compare_supplier_options — Ranks eligible suppliers by cost, lead time, and reliability.
flag_for_human_review — Triggers the HITL approval flow for high-impact decisions.



🚀 Setup & Execution


Dependencies: pip install anthropic pandas
API Key: Add your Anthropic API key to the Colab Secrets manager as Anthropic_API_KEY.
Run Pipeline: Execute cells sequentially to load synthetic data, tool definitions, and agent prompts.
Interactive Interface: Use the ipywidgets UI (Cell 12) to test the agent with natural language queries (e.g., "We have a big graduation event in 10 days. Check A-class items and recommend restocking.").
Telemetry: Check the cost and score consistency reports generated by the telemetry framework (Cell 13).
